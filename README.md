# Matrix Trade Outbound-to-Inbound Automation Tool (React + TypeScript)

A modern **React 19 + TypeScript + Vite + Tailwind CSS** application designed to automate the Matrix custodian trade settlement workflow:

1. **Ingests Outbound Trade Files** generated by the backend service in WinSCP `/MATRIX/outbound/` (e.g. `TRADE.YYYYMMDD.C*`).
2. **Computes Exact Settlement Units & Values**: Calculates trade Units from NAV ($\text{Units} = \frac{\text{Dollars}}{\text{NAV}}$) and formats the Matrix settlement response status (`037` Confirmed / Settled), reject code (`000`), and user-specified settlement date.
3. **Generates Validated Inbound Response Files**: Produces 200-character fixed-width records (`LRECL 200`) formatted to match [`MatrixTradeResponseFixedWidthFileProcessor.cs`](file:///D:/source/repos/congruent-core-trade/Congruent.Core.Trade.Consumer/FileProcessors/Matrix/MatrixTradeResponseFixedWidthFileProcessor.cs) for WinSCP `/MATRIX/inbound/` (naming: `TRADE.YYYYMMDD`).
4. **Automated API Trigger**: Built-in trigger invoking `POST /api/v1/TradeOutboundFileGeneration/TriggerInboundFileProcess` with real-time feedback and cURL generation.

## 🌐 Deploy to GitHub Pages (Automated via GitHub Actions)

The repository includes a ready-to-use GitHub Actions workflow at `.github/workflows/deploy.yml`.

### Step 1: Initialize Git and Push to GitHub
```bash
cd d:\source\repos\trade-file-formatter
git init
git add .
git commit -m "feat: Matrix Trade Automation React TypeScript app"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<REPO-NAME>.git
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** ➔ **Pages** (in the left sidebar).
3. Under **Build and deployment** ➔ **Source**, select **GitHub Actions**.
4. GitHub Actions will automatically trigger `.github/workflows/deploy.yml`, build the app, and deploy it to:
   ```
   https://<YOUR-USERNAME>.github.io/<REPO-NAME>/
   ```
